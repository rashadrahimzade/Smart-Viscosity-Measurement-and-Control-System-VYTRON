## 🐛 Reporting Issues

If you find a bug or unexpected behavior, please open a GitHub Issue and include:

- A clear title and description
- Steps to reproduce (if applicable)
- Hardware version (Mega 2560, Nano, JSS-860H, etc.)
- Firmware version / commit hash
- Photos or screenshots (if relevant)
- Expected vs. actual behavior

## 📬 Design Feedback & Suggestions

You are welcome to share design suggestions, feature ideas, or improvement feedback. Please open a GitHub Issue with:

- **Title:** `[FEEDBACK] <short summary>`
- **Description:** What you observed and what you suggest changing
- **Context:** Which part of the system (mechanical, electrical, firmware, documentation)
- **Photos or drawings** (if applicable)

> Please note: Because this project is **All Rights Reserved**, submitting feedback or ideas does not grant permission to modify or redistribute the project. Any implementation of suggestions remains the author's property.
